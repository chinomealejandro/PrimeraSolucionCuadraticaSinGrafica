¿Cómo se calcula?

Para resolver una ecuación cuadrática de la forma ax² + bx + c = 0, utilizamos la fórmula general:

x = [-b ± √(b² - 4ac)] / (2a)

Donde D = b² - 4ac es el discriminante:

  • Si D > 0: Dos soluciones reales distintas
  • Si D = 0: Una solución real doble
  • Si D < 0: Dos soluciones complejas conjugadas

Esta aplicación resuelve ecuaciones cuadráticas de la forma:

Control de decimales

Esta versión incluye un control para ajustar el número de decimales mostrados en las soluciones:

  • Usa los botones + y − para aumentar o disminuir la precisión
  • El rango permitido es de 0 a 10 decimales
  • El cambio se aplica inmediatamente a los resultados mostrados

La Fórmula General para ecuaciones cuadráticas

La fórmula general para resolver ecuaciones cuadráticas es:

x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}

Esta fórmula proporciona las soluciones (o raíces) de cualquier ecuación cuadrática de la forma ax² + bx + c = 0.

Precisión decimal

La precisión en la presentación de resultados es importante en matemáticas aplicadas:

  • Para cálculos teóricos o exactos: usar más decimales
  • Para aplicaciones prácticas: usar menos decimales según la precisión requerida
  • En esta aplicación puedes ajustar la precisión con los controles de decimales

Interpretación geométrica

Las soluciones de una ecuación cuadrática representan los puntos donde la parábola y = ax² + bx + c intersecta el eje X.

El discriminante

La expresión dentro de la raíz cuadrada, D = b² - 4ac, se llama discriminante y determina la naturaleza de las soluciones:

D > 0: Dos soluciones reales distintas (la parábola corta el eje X en dos puntos)
D = 0: Una solución real doble (la parábola toca el eje X en un solo punto)
D < 0: Dos soluciones complejas conjugadas (la parábola no corta el eje X)
