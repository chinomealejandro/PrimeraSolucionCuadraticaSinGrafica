Acerca de esta aplicación

Esta aplicación resuelve ecuaciones cuadráticas de la forma:

ax² + bx + c = 0

Fue desarrollada como una implementación web del código Python original que pedía coeficientes al usuario y calculaba las soluciones.

Ejemplos de ecuaciones cuadráticas

Haz clic en cualquier ejemplo para cargarlo en la calculadora:

Ejemplo 1: x² - 3x + 2 = 0
Solución: x₁ = 2, x₂ = 1 (D > 0, parábola que corta en dos puntos)
Ejemplo 2: x² - 2x + 1 = 0
Solución: x = 1 (Doble) (D = 0, parábola tangente al eje X)
Ejemplo 3: x² + 2x + 5 = 0
Solución: Compleja (D < 0, parábola que no corta el eje X)
Ejemplo 4: 2x² - 4x - 6 = 0
Solución: x₁ = 3, x₂ = -1 (D > 0, parábola que abre hacia arriba)
Ejemplo 5: -x² + 4 = 0
Solución: x₁ = 2, x₂ = -2 (D > 0, parábola que abre hacia abajo)

La Fórmula General para ecuaciones cuadráticas

La fórmula general para resolver ecuaciones cuadráticas es:

x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}

Esta fórmula proporciona las soluciones (o raíces) de cualquier ecuación cuadrática de la forma ax² + bx + c = 0.

Interpretación gráfica de las soluciones

Las soluciones de la ecuación cuadrática corresponden a los puntos donde la gráfica de la función y = ax² + bx + c (una parábola) intersecta el eje X:

D > 0: Dos soluciones reales distintas (la parábola corta el eje X en dos puntos)
D = 0: Una solución real doble (la parábola toca el eje X en un solo punto - vértice)
D < 0: Dos soluciones complejas conjugadas (la parábola no corta el eje X)

Propiedades de la parábola

  • Si a > 0, la parábola abre hacia arriba (forma de U)
  • Si a < 0, la parábola abre hacia abajo (forma de ∩)
  • El vértice de la parábola está en el punto (-b/(2a), f(-b/(2a)))
  • El eje de simetría es la línea vertical x = -b/(2a)
